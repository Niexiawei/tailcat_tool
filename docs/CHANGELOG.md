# 变更记录（CHANGELOG）

本文件记录本项目的**所有用户可见变更**。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## 记录规则（对贡献者与代理同样有效）

1. **每个改动用户行为的提交，都必须在同一次提交里更新本文件。** 判断标准很简单：用户能感知到（界面、行为、文案、配置格式、文件位置、体积、依赖要求）。纯重构、纯测试、纯内部整理不必单独记一条，除非它改变了行为。
2. 写在最上面的 `## [未发布]` 里，按类别归入：`新增` / `变更` / `修复` / `移除` / `安全` / `依赖`。没有内容的类别不要留空标题。
3. 一条一行，**以用户视角描述结果**，而不是罗列函数名：
   - 好：`设备编辑器新增“本地 ADB 直连”，可填 IP:端口 或 USB 序列号`
   - 差：`add DirectADB field to Profile`
4. 需要解释"为什么"时，另起一行缩进说明；重大取舍请在 `docs/architecture.md` 的「设计决策记录」里补一行，而不是塞进这里。
5. 破坏性变更（配置文件格式、文件位置、去掉的功能）必须写进 `变更` 或 `移除`，并在条目末尾标注 **（破坏性）**。
6. 发布时把 `未发布` 改成 `## [x.y.z] - YYYY-MM-DD`，并在文件顶部补一条链接；不要事后修改已发布的段落。

## [0.1.0] - 2026-11-15

首个 Go 版：把原来的 SwiftUI 应用（仅 macOS 13+ / arm64）重写为跨平台单文件应用，
macOS（arm64/amd64）、Windows（amd64）、Linux（amd64）功能一致。纯 Go、无 cgo，任意机器可交叉编译。

### 新增

- **内嵌传输层**：`github.com/tailscale/tailcat` 以库的方式使用，转发、探测、客户端身份、DERP 地图全部在进程内完成。**不再需要安装 `tailcat` 命令行**，只需 `adb`（必需）与 `scrcpy`（可选）。
- **每设备独立会话**：每条通道有自己的本地端口（固定或 5556–5655 自动分配）、自己的 ADB serial、自己的 Tailcat 身份，可多台同时连接、互不串台。
- **本地 ADB 直连**：添加设备时可选「本地 ADB 直连」，填 `IP:端口` 或 USB 序列号（如 `emulator-5554`），走本机 adb server，不经过 Tailcat、不使用设备身份。`IP:端口` 会先执行 `adb connect`，USB 序列号不会。
- **外部干预检测与「等待处理」**：在本机执行 `adb disconnect`、或设备被映射到别的本地端口时，应用会停下来让用户选 **重新连接 / 改用其他本地端口 / 稍后处理**，不再默默重试、也不会把用户刚断开的连接又偷偷连回去。
- **历史库**：任务、通道日志、批量连通测试结果存入 `<配置目录>/history.db`（SQLite，纯 Go 驱动），重启后任务面板仍有上次的记录。删掉该文件即清空历史，不影响使用。
- **批量连通测试**：一键测试全部设备的 Tailcat 可达性，3 台并发、每次时长上限、可取消，显示延迟与直连/中继路径，不建立也不断开 ADB 连接。
- **组件安装**：按平台自动安装缺失工具（macOS `brew`、Windows `winget`、Linux `apt`/`dnf`/`pacman`），Homebrew 会关闭自动更新/升级/清理；无法自动安装的组合（如 winget 的 scrcpy）会明确提示手动安装并支持手填路径。
- **设备操作**：安装 APK、上传、下载（含本地目录选择）、单条 Shell 命令、终端、屏幕控制（scrcpy）、链路探测、刷新设备信息（型号/代号/Android/序列号/Shell 权限）。
- **界面**：侧栏分组（我的设备 / 临时设备）、底部工具健康状态、概览与日志两页、任务面板、托盘菜单（每设备子菜单）、关闭窗口保活、单实例（第二次启动唤回已有窗口）。
- 演示模式 `--demo`：模拟设备，不读配置、不碰凭据库、不执行真实命令。

### 变更

- 会话状态由 7 个改为 8 个，新增「等待处理」（`needsAction`）。
- 断开顺序：先关闭本地监听与活跃连接、再执行 `adb disconnect`（原 Swift 版相反），避免断开后又接进新连接。
- 端口就绪判定：绑定成功即就绪，不再解析 stderr、不再有 5 秒等待。
- 设备身份改为由本进程生成/读取（格式与 `tailcat --key=` 完全一致，0600），不再交给外部命令行。
- 凭据长度上限改为 2560 字节（Windows 凭据管理器的最小上限，三平台统一）。
- Windows 的进程终止为整树 `taskkill /T /F`（无 SIGTERM 可用）。

### 移除

- **外部 `tailcat` 可执行文件依赖**（工具设置里不再有该路径，安装器不再提供它）。
- **`tailcat-adb` 地址簿导入**（配置目录里的地址簿路径、`legacyUsername` 字段、工具栏「导入地址簿」按钮）。CLI 模式已移除，也没有从 Swift 版迁移数据的需求 **（破坏性）**。
- **CLI 外部会话识别**（`bridges/*.pid`、`ps`/`lsof` 扫描、socat 桥归属）：应用现在只管理自己建立的通道。
- 内联 DERP JSON 的本地回环 HTTP 服务（库直接接受内存中的 DERP 地图）。
- macOS 凭据助手可执行文件：改用系统凭据库直连，代价是开发期 `go run` 重建后可能再要一次 Keychain 授权。

### 修复

- 脱敏输出在超长行（>32 KiB）之后会连带丢弃紧随其后的正常行；现在只丢弃该行到下一个换行为止。
- 监视循环与干预检测互相等待造成死锁（持有管理器锁时再次上锁）。
- 历史库关闭后再写入会因向已关闭通道发送而 panic。
- 首次启动时配置目录尚不存在，导致历史库无法打开；现在先创建目录（0700）。
- 历史库"写入后立刻读取"可能读到空结果（队列未排空）。

### 安全

- 连接地址（`tc...`）只存系统凭据库，配置文件、日志、任务输出、tailcat 日志全部经过脱敏；跨多次读取被切断的凭据也不会露出半截。
- 配置目录 0700、配置文件 0600，身份目录 0700、私钥 0600，写入原子化并拒绝符号链接。
- 身份文件存在即复用，损坏时报错并保留原文件，绝不静默换钥；同名并发初始化由文件锁保证只生成一次。
- 设备私钥只以路径与 `nodekey:` 公钥出现在日志中，私钥仅在进程内存中使用。

### 依赖

- 新增 `github.com/egoist/mygo` v0.9.1（GUI，纯 Go）、`github.com/oneo-me/onevra/source` v2026.18（组件库）、`github.com/tailscale/tailcat` v0.7.0（传输，含 `tailscale.com` 传递依赖）、`modernc.org/sqlite` v1.62.0（纯 Go SQLite）。
- 要求 Go 1.27.3 及以上。
- 单文件体积：默认 46.9 MB、`-ldflags "-s -w"` 后 32.5 MB（Windows/amd64 实测）。

### 已知限制

- 尚未在真机上联调：ADB 实链路、scrcpy 窗口、设备授权流程、干预弹窗都只有自动化测试与 `--demo` 验证。
- 未产出 dmg / msi / deb 安装包与签名。
- `adb kill-server` 会表现为多条「入口被移除」提示；「监听器丢失」与「ADB 服务重启」两种聚合提示尚未实现。
- 配置读取失败只显示一条提示，没有独立的启动错误页。
- 历史只有"重启后载入任务面板"，没有按设备/时间筛选的界面。
